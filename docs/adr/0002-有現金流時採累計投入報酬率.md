# 有現金流時採累計投入報酬率

Status: accepted

加入每月入金後，使用者在開局後會有持續的現金流入，定期定額則每月固定投入每月入金、不含初始資金，買進持有則僅有期初的初始資金。我們決定三方皆以「累計投入報酬率」（`(總資產 − 累計投入本金) ÷ 累計投入本金`）作為報酬率與資產曲線的計算口徑，而非時間加權報酬率（TWR）或內部報酬率（MWR / XIRR）。

## Considered Options

- **時間加權報酬率（TWR）**：在每次現金流發生時切分子期間並連乘，完全排除入金時點對報酬率的影響。雖然能衡量純粹的選時操作，但由於定期定額每月領取每月入金後即全數買入股票（幾乎不留現金），其 TWR 曲線會與買進持有高度重疊，導致模擬器無法呈現定期定額在震盪或下跌市場中分批攤平成本的差異。
- **內部報酬率（MWR / XIRR）**：為考慮資金停留時間的年化報酬率，初期單日小幅漲跌換算成年化後極端放大，不適合繪製從 0% 起算的每日資產曲線。
- **累計投入報酬率**：以各自截至當下的累計投入本金為分母，直覺反映實際投入本金的淨賺賠比例，且使用者的總損益（總資產 − 累計投入本金）恆等於已實現損益加未實現損益。

## Consequences

- 資產曲線呈現的是相對於當下累計投入本金的報酬率；當新入金使分母擴大時，帳面報酬率比例會自然往 0% 方向稀釋，這屬於口徑特性而非資產減少。
- 介面需同時呈現累計投入本金與總損益，讓使用者能搭配報酬率解讀絕對獲利金額。
