# 存檔以種子重算行情

存檔只記錄種子、開局設定、進度（第幾個交易日的第幾個 tick）、交易紀錄與介面設定，讀檔時用種子把行情重算到同一個 tick，而不是保存整段 K 棒。這樣存檔只有幾 KB，適合放在 `localStorage`；代價是讀檔要重算，而且行情必須完全由種子決定。

## Consequences

- 行情絕不能受使用者的任何操作（買賣、暫停、速度切換）影響，否則重算出的行情會和原本不同。
- 任何改變亂數使用順序或模型參數的引擎修改，都會讓舊存檔重算出不同行情。因此存檔帶有引擎版本號；版本不符時不嘗試讀取，提示「行情引擎已更新，需重新開局」。修改引擎時必須遞增版本號。
