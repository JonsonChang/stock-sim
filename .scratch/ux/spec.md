# 主畫面操作體驗改善

Status: ready-for-agent

## Problem Statement

主畫面上方資訊列把播放控制、圖表顯示開關、行情狀態與局務按鈕約 15 個控制項攤成一排，沒有分組也沒有主次，找東西要從頭掃到尾。桌面版看不到現價的漲跌與我的報酬率（只有手機版有），要知道自己賺賠得把視線移到右側面板。下單時賣出沒有「全部持股」捷徑，想出清必須自己輸入股數；成交後只有一行小字回饋，不確定是否成交；也沒有任何鍵盤快捷鍵，暫停、切換倍速、下單都只能靠滑鼠。

## Solution

以小幅調整為原則，維持單檔 vanilla 架構與現有深色風格，以桌面版為主、同時確保手機版不被破壞：

- 資訊列分成「播放」「行情狀態」「我的績效」「局務」四組，均線、KD、揭曉移到圖表左上角與 K 棒週期切換同列。
- 桌面版顯示漲跌與我的報酬率；主畫面一律用「我的報酬率」稱呼使用者的累計投入報酬率。
- 下單區新增賣出用的「全部持股」捷徑。
- 成交後顯示短暫的成交提示。
- 新增不會直接成交的鍵盤快捷鍵。

## User Stories

1. As a 使用者, I want 資訊列依用途分組, so that 我能一眼找到播放控制、看到行情與自己的績效，局務按鈕不會干擾看盤。
2. As a 使用者, I want 均線、KD、揭曉開關放在圖表上與 K 棒週期切換同列, so that 圖表要顯示什麼都在圖表上調整。
3. As a 使用者, I want 在桌面版資訊列看到現價的漲跌（相對前一交易日收盤）與我的報酬率, so that 不用移動視線到右側面板就能掌握盤勢與自己的賺賠。
4. As a 使用者, I want 主畫面各處都用「我的報酬率」稱呼同一個數值, so that 不會誤以為「總資產報酬」是另一個指標。
5. As a 使用者, I want 按「全部持股」把數量設成目前持有股數, so that 出清部位不用自己輸入股數。
6. As a 使用者, I want 成交後看到「✓ 買進 1,000 股 @ 102.50」之類的短暫提示, so that 我確定市價單已經成交。
7. As a 使用者, I want 按空白鍵暫停／播放、按 1／2／3 切換 1x／5x／50x, so that 不用滑鼠也能控制行情。
8. As a 使用者, I want 按 B／S 只會切換買賣並把焦點移到數量輸入框、按 Enter 才送出, so that 誤觸按鍵不會意外成交。

## Implementation Decisions

- 資訊列分組由左到右：播放（暫停／播放、倍速）｜行情狀態（現價、漲跌、日期、第 N 年）｜我的績效（我的報酬率）｜局務（種子、投資報告、重新開局，靠右）。
- 漲跌沿用手機版既有計算（相對前一交易日收盤），紅漲綠跌。
- 「全部持股」與「全部資金」並列，只填數量不下單；部位為 0 股時停用。
- 成交提示約 2 秒，買進紅、賣出綠；桌面版顯示在下單區上方，手機版因下單面板會關閉，顯示在圖表上方。
- 焦點在任何輸入框時，所有快捷鍵停用；投資報告開啟時沿用既有 Esc 行為。
- 重新開局面板行為不變，只需在新版面下正常展開。
- 投資報告內的「總報酬率」維持原名。

## Testing Decisions

- 本次改動集中在介面，`sim-core.js` 不應變動；`node --test test/sim-core.test.js` 需維持全數通過。
- 每張 issue 以 Chrome 實際操作驗收桌面版，並以 390×844 裝置模擬確認手機版不受影響。

## Out of Scope

- 重新開局／設定流程的重新設計。
- 視覺重設計（設計 token、整體配色與字級翻新）。
- 投資報告內的版面與用語。
