# 08: 一半資金、一半持股取代全部資金、全部持股

**What to build:** 市價單的數量列由「1 張｜全部資金｜全部持股」改為「1 張｜一半資金｜一半持股」。按下只填入股數並更新預估成交金額，不直接下單。

- 一半資金：以一半現金能買進的最大股數（含手續費）
- 一半持股：目前部位股數除以 2，無條件捨去

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 「全部資金」「全部持股」按鈕移除，改為「一半資金」「一半持股」
- [ ] 一半資金填入的股數，其買進總額（含手續費）不超過現金的一半，且再多 1 股就會超過
- [ ] 一半持股填入 floor(部位股數 / 2)
- [ ] 計算結果為 0 股時按鈕停用（例如部位僅 1 股、現金一半買不起 1 股），條件改變後自動恢復
- [ ] 手機版下單面板兩顆按鈕皆顯示，排版不擠壓
- [ ] README「下單」段落同步更新
- [ ] `node --test test/sim-core.test.js` 全數通過；以 Chrome 人工檢查桌面與手機版
