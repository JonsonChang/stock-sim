# 股票投資模擬器

Status: ready-for-agent

## Problem Statement

我想練習看盤與買賣判斷，但真實市場一天只有一根日 K 棒，練習太慢，而且賠的是真錢。現有的模擬工具不是直接重播歷史行情（可以事後查到、會被記住），就是用過於單純的隨機漫步產生行情：沒有肥尾、沒有波動群聚、沒有趨勢段，看起來不像真的市場，練出來的盤感也沒有意義。我也沒辦法客觀知道自己的操作，到底有沒有比單純「買進持有」或「定期定額」更好。另外，每次關掉瀏覽器就得從頭開始，沒辦法長期練習。

## Solution

一個在瀏覽器中直接開啟的單一網頁沙盒。系統用統計上貼近真實市場、但每次都不同的模型產生單一股票行情，K 棒會在盤中隨 tick 即時長出來。使用者用初始資金隨時以市價單買進或賣出，系統依台股規則計算手續費與證交稅，並即時顯示使用者與兩個比較基準（買進持有、定期定額）的報酬率與資產曲線。進度會自動存檔，下次開啟時停在離開時的 tick，可以接著玩。桌面版和手機版都能操作。

## User Stories

### 開局與行情

1. As a 使用者, I want 開局時就有約 250 個交易日的歷史 K 棒, so that 我一進場就有線圖可以判斷，不用面對空白畫面。
2. As a 使用者, I want 行情有肥尾（偶爾出現大漲大跌）, so that 我能練習面對真實市場的極端波動。
3. As a 使用者, I want 行情有波動群聚（大波動之後常跟著大波動）, so that 我能練習辨識高風險期間。
4. As a 使用者, I want 行情有多頭、空頭、盤整等不同的市場狀態並會切換, so that 長期線圖會出現真實的趨勢段與盤整段。
5. As a 使用者, I want 行情偶爾出現跳躍與開盤跳空, so that 我能體驗突發消息造成的缺口。
6. As a 使用者, I want 報酬的方向無法從過去的價格預測, so that 模擬器不會被簡單規則破解，練習才有意義。
7. As a 使用者, I want 成交量和價格波動大小相關, so that 我能練習用量價關係判斷行情。
8. As a 使用者, I want 單一交易日的漲跌幅不超過 ±10%, so that 行情符合台股漲跌停規則。
9. As a 使用者, I want 盤中價格碰到漲跌停就停在漲跌停價, so that 會自然出現一字漲停、觸及漲停後回落等型態。
10. As a 使用者, I want 價格符合台股升降單位, so that 報價看起來像真的台股。
11. As a 使用者, I want 盤中波動呈 U 型（開盤與收盤附近較劇烈）, so that 盤中走勢接近真實市場。
12. As a 使用者, I want 每次開局的行情都不同, so that 我無法背下行情。
13. As a 使用者, I want 畫面上顯示目前的種子，並可以在開局時輸入種子, so that 我可以重玩同一段行情，或和別人比較同一盤的操作。

### 時間與播放

14. As a 使用者, I want 每個交易日在 1x 速度下約 10 秒跑完, so that 我能看著 K 棒長出來並即時決策。
15. As a 使用者, I want 切換 1x、5x、20x 速度, so that 我可以快轉沒有操作意圖的期間。
16. As a 使用者, I want 隨時暫停與繼續, so that 我可以停下來思考。
17. As a 使用者, I want 交易日之間不停頓，收盤後下一根 K 棒立刻開盤, so that 節奏流暢。
18. As a 使用者, I want 一局最多進行 30 年（模擬期限，從第一個即時交易日起算），到期後行情停止、不能再下單但仍可檢視, so that 練習有明確的期間。

### K 線圖與圖表操作

19. As a 使用者, I want 看到 K 線圖與成交量, so that 我能判斷行情。
20. As a 使用者, I want 用滑鼠滾輪縮放可視 K 棒數量，範圍從 20 根到全部, so that 我能在短線細節和長期趨勢之間切換。
21. As a 使用者, I want 拖曳平移 K 線圖, so that 我能回顧較早的行情。
22. As a 使用者, I want 圖表預設跟隨最新的 K 棒, so that 我不用手動捲動就能看到即時行情。
23. As a 使用者, I want 平移後圖表停止跟隨，並出現「回到最新」按鈕, so that 回顧歷史時畫面不會被拉走，看完也能一鍵回來。
24. As a 使用者, I want 滑鼠移到 K 棒上時顯示該交易日的開高低收與成交量, so that 我能查看精確數字。
25. As a 使用者, I want K 棒用台股慣例的紅漲綠跌配色, so that 符合我的閱讀習慣。
26. As a 使用者, I want K 線圖上的 K 棒標記我的買賣點（▲ 買、▼ 賣）, so that 我能檢討自己的進出場時機。

### 揭曉開關

28. As a 使用者, I want 一個預設關閉的揭曉開關, so that 我平時看不到市場狀態，練習才有意義。
29. As a 使用者, I want 開啟揭曉後，K 線圖背景以淡色帶加文字標籤顯示每段時間的市場狀態, so that 我能事後驗證自己對行情的判斷。
30. As a 使用者, I want 開啟揭曉後，跳躍發生的 K 棒上方出現標記, so that 我知道哪些大波動是跳躍造成的。

### 交易

31. As a 使用者, I want 用初始資金（預設 100 萬）開始, so that 我有一個明確的起點。
32. As a 使用者, I want 按下買進或賣出時，以當下 tick 價立即全數成交, so that 操作簡單直接。
33. As a 使用者, I want 用股數下單，並可以買零股, so that 我能精細調整部位大小。
34. As a 使用者, I want 有「1 張」「全部資金」等快捷按鈕, so that 我能快速下常用數量的單。
35. As a 使用者, I want 暫停時也能下單，以暫停前最後一個 tick 價成交, so that 我可以停下來想清楚再交易。
36. As a 使用者, I want 漲跌停時仍能以漲跌停價成交, so that 規則單純，不會因為鎖死而無法操作。
37. As a 使用者, I want 每筆成交收取 0.1425% 手續費、最低 20 元, so that 交易成本貼近真實。
38. As a 使用者, I want 賣出時另外扣 0.3% 證交稅, so that 交易成本貼近真實。
39. As a 使用者, I want 下單金額超過現金時不能買進、超過持有股數時不能賣出, so that 不會出現負現金或放空。
40. As a 使用者, I want 下單前看到預估成交金額與費用, so that 我知道這筆交易的成本。

### 部位與績效

41. As a 使用者, I want 看到目前部位的股數、平均成本（含手續費）、現金與總資產, so that 我掌握自己的狀況。
42. As a 使用者, I want 看到未實現損益與已實現損益, so that 我知道賺賠來自哪裡。
43. As a 使用者, I want 看到我從第一個即時交易日起算的報酬率, so that 我知道整體表現。
44. As a 使用者, I want 系統同時計算「買進持有」比較基準的報酬率, so that 我知道自己的操作有沒有勝過單純持有。
45. As a 使用者, I want 系統同時計算「定期定額」比較基準的報酬率（每 20 個交易日以開盤價投入初始資金的 1/12，直到資金用完）, so that 我能和紀律型投資做比較。
46. As a 使用者, I want 比較基準也要扣手續費, so that 比較是公平的。
47. As a 使用者, I want 勾選每個比較基準要不要顯示, so that 畫面只呈現我關心的比較。
48. As a 使用者, I want 在 K 線圖與成交量下方看到資產曲線窗格，Y 軸是報酬率 %，從 0% 起算, so that 我能看出自己和比較基準隨時間的差距。
49. As a 使用者, I want 資產曲線和 K 線圖共用時間軸，縮放和平移同步, so that 我能直接對照「這段下跌時我的資產怎麼變化」。
50. As a 使用者, I want 資產曲線最右端隨每個 tick 即時更新, so that 我能看到當下的盤中績效。
51. As a 使用者, I want 預產的歷史區段在資產曲線上留白, so that 圖上不會出現我沒有參與的績效。
52. As a 使用者, I want 看到交易紀錄清單，欄位包含交易日、買/賣、股數、成交價、手續費、證交稅，最新的放最上面, so that 我能回顧每筆操作。

### 重新開局

53. As a 使用者, I want 一個「重新開局」按鈕，按下後展開設定區，可以改種子、起始價、初始資金, so that 我能開始新的一局。
54. As a 使用者, I want 重新開局用頁面內的按鈕確認，而不是跳出瀏覽器對話框, so that 不會誤按，也不會被對話框打斷。
55. As a 使用者, I want 開局設定在局中無法修改, so that 一局的條件從頭到尾一致。

### 存檔

56. As a 使用者, I want 系統在每筆成交後、每個交易日收盤時，以及切換分頁或關閉頁面時自動存檔, so that 我不需要記得手動存檔。
57. As a 使用者, I want 關掉瀏覽器後再開啟，回到離開時的同一個 tick, so that 我能接著玩，不用每次重來。
58. As a 使用者, I want 回來時一律處於暫停狀態, so that 行情不會在我還沒進入狀況時就開始跑。
59. As a 使用者, I want 速度、比較基準勾選、揭曉開關等介面設定也一起保存, so that 回來時畫面和離開時一致。
60. As a 使用者, I want 重新開局時覆蓋舊存檔, so that 只保留一份存檔，不會混淆。
61. As a 使用者, I want 引擎更新造成存檔不相容時，看到「行情引擎已更新，需重新開局」的提示, so that 不會讀到錯誤的行情。
62. As a 使用者, I want 30 年的存檔也能在 3 秒內讀檔完成, so that 回來時不用久等。

### 手機版

63. As a 手機使用者, I want 螢幕寬度 ≤ 768px 時改用手機版面, so that 小螢幕也能操作。
64. As a 手機使用者, I want 三個圖表窗格佔畫面上方約 55%, so that 主要資訊一眼可見。
65. As a 手機使用者, I want 一列常駐的現價、漲跌%、總資產報酬%、速度切換, so that 我不用切換分頁就能看到關鍵數字。
66. As a 手機使用者, I want 底部固定的「買進／賣出」大按鈕，按下後從底部滑出下單面板, so that 我隨時能快速下單。
67. As a 手機使用者, I want 部位、績效、交易紀錄用分頁切換, so that 不需要一直捲動頁面。
68. As a 手機使用者, I want 用兩指縮放圖表, so that 操作方式符合手機習慣。
69. As a 手機使用者, I want 用單指左右拖曳平移圖表, so that 我能回顧歷史行情。
70. As a 手機使用者, I want 長按 K 棒顯示該交易日的開高低收與成交量, so that 沒有滑鼠也能查看詳情。

## Implementation Decisions

- **技術選型**：單一 HTML 頁面，使用原生 JavaScript 與 Canvas，不需安裝、不需建置；模擬核心是獨立的 JavaScript 模組，瀏覽器和 Node 都能載入。
- **模組劃分**：
  - **模擬核心**（headless，不碰 DOM）：包含價格引擎、盤中 tick 產生、帳務、比較基準、存檔序列化。這是唯一的測試接縫。
  - **介面層**：Canvas 圖表（K 線、成交量、資產曲線三個窗格）、播放控制、下單面板、部位／績效／交易紀錄面板、重新開局、手機版面與觸控、`localStorage` 讀寫與自動存檔時機。
- **模擬核心對外介面**（概念層級）：
  - 以「種子＋開局設定（起始價、初始資金）」建立一局；或由存檔還原，引擎版本不符時拒絕。
  - 推進一個 tick。
  - 對當下 tick 價下市價單（買進／賣出，指定股數），回傳成交結果或拒絕原因（現金不足、股數不足）。
  - 讀取狀態：K 棒序列（含正在形成的當日 K 棒）、現價、部位、現金、總資產、已實現／未實現損益、交易紀錄、兩個比較基準與使用者的報酬率、資產曲線（每個交易日收盤值加上當下即時值）、每個交易日的市場狀態與跳躍標記（供揭曉開關使用）。
  - 產生存檔資料。
- **價格模型**：
  - 對數報酬（GBM），所以價格不會變負。
  - 雜訊用 Student-t 分配（ν=4），並縮放成變異數 1。
  - 條件波動用 GARCH(1,1)，α=0.08、β=0.90，長期日波動 1.5%～2.5%。
  - 三種市場狀態用 Markov 切換：多頭 μ=+0.08%/交易日；空頭 μ=−0.10%/交易日、σ×1.3；盤整 μ≈0；每個交易日維持原狀態的機率：多頭 0.991、空頭與盤整 0.97（多頭較持久，參考 VT 長期年化約 +7%～8%）。
  - Poisson 跳躍：每個交易日發生機率 1%～2%，幅度 ±5%～9%；另外有開盤跳空。
  - 成交量 ∝ |報酬| × 波動率 × 隨機因子。
- **盤中路徑**：
  - 每個交易日 270 個 tick，每個 tick 的對數價格增量為 μ/N + (σ/√N)·z，盤中波動權重呈 U 型。
  - K 棒的開高低收隨 tick 即時更新。
  - tick 價格碰到漲跌停（前一交易日收盤 ±10%）就截斷在漲跌停價，跳躍和開盤跳空同樣適用。
  - 價格依台股升降單位取整。
- **開局預設**：預產 250 個交易日的歷史（價格引擎的暖機期間不顯示），起始價 100 元，初始資金 1,000,000 元。種子預設隨機產生。
- **時間**：1x＝10 秒/交易日，5x＝2 秒，20x＝0.5 秒，另有暫停。交易日之間不停頓。播放節奏由介面層控制，模擬核心只提供「推進一個 tick」。
- **交易規則**：
  - 只有市價單，以當下 tick 價全數成交，不模擬滑價和掛單簿。
  - 可買零股，下單單位是股數。
  - 手續費 0.1425%，最低 20 元，整股和零股一律適用。
  - 賣出時另扣證交稅 0.3%。
  - 漲跌停時仍可成交。
  - 不可放空、不可融資。
  - 平均成本計入買進手續費。
- **比較基準**：從第一個即時交易日開始計算。
  - **買進持有**：在第一個即時交易日開盤，用全部初始資金買進（股數無條件捨去，扣手續費），之後永不賣出。
  - **定期定額**：從第一個即時交易日起，每 20 個交易日以當期第一個交易日的開盤價投入初始資金的 1/12，股數無條件捨去，扣手續費，資金用完就停止。
- **行情與使用者操作完全獨立**：價格只由種子決定，使用者的買賣、暫停、速度切換都不影響行情。這是存檔策略的前提（見 ADR-0001）。
- **存檔**（見 ADR-0001）：
  - 存在 `localStorage`，每個瀏覽器只保留一份存檔。
  - 存檔內容：引擎版本號、種子、開局設定、進度（第幾個交易日的第幾個 tick）、交易紀錄、介面設定（速度、比較基準勾選、揭曉開關）。
  - 讀檔時用種子重算行情到同一個 tick，再重放交易紀錄還原帳務。
  - 引擎版本號不符時拒絕讀檔，提示需要重新開局。修改引擎的亂數使用方式或模型參數時，必須遞增版本號。
  - 自動存檔時機：每筆成交後、每個交易日收盤時、`visibilitychange` 或 `pagehide` 發生時。
  - 回來時一律處於暫停狀態。
  - 重新開局時覆蓋存檔。
- **版面**：
  - 桌面版：左側約 75% 放三個窗格（K 線、成交量、資產曲線），右側面板由上而下是行情資訊與速度控制、下單、部位、績效（含比較基準勾選）、交易紀錄。
  - 手機版（寬度 ≤ 768px）：
    - 上方是三個窗格，約佔畫面 55%
    - 中間是常駐的資訊列
    - 底部固定「買進／賣出」按鈕，按下後滑出下單面板
    - 部位、績效、交易紀錄改成分頁
- **互動**：
  - 桌面：滾輪縮放（20 根到全部）、拖曳平移、滑鼠移過顯示 K 棒詳情。
  - 手機：兩指縮放、單指拖曳平移、長按顯示 K 棒詳情。
  - 預設跟隨最新 K 棒，平移後停止跟隨並顯示「回到最新」按鈕。三個窗格的縮放和平移同步。
- **揭曉開關**：預設關閉，狀態會存檔。開啟後用中性淡色背景帶加文字標籤標示市場狀態（不使用紅綠色，避免和 K 棒混淆），跳躍日在 K 棒上方加標記。
- **重新開局**：用頁面內的設定區與確認按鈕，不使用瀏覽器原生對話框（`alert`、`confirm`）。

## Testing Decisions

- **好的測試只驗證外部行為**：一律透過模擬核心的公開介面（建立一局、推進 tick、下單、讀取狀態、存檔與讀檔）來測，不測內部函式、中間變數或亂數實作細節。統計測試使用固定種子，結果才可以重現。
- **測試接縫**：只有一個，就是模擬核心。價格引擎是模擬核心的內部實作，它的統計特性透過模擬核心輸出的 K 棒來驗證。
- **要測的行為**：
  - **行情統計**（固定種子，5,000 個交易日）：日報酬峰度 > 3；報酬 lag-1 自相關的絕對值 < 0.05；|報酬| 在 lag 1、5、20 的自相關都為正值；長期價格序列中同時出現上升段與下降段。
  - **K 棒合法性**：每根 K 棒都滿足 最高 ≥ max(開, 收)、最低 ≤ min(開, 收)；收盤價等於當日最後一個 tick 價；每個交易日的漲跌幅（相對前一交易日收盤）不超過 ±10%；所有價格都符合升降單位。
  - **決定性**：相同種子產生完全相同的行情；在不同時間點下單或完全不下單，都不改變行情。
  - **帳務**：買進的手續費計算與最低 20 元；賣出另扣證交稅；一買一賣之後的現金與已實現損益數字正確；零股成交；現金不足時拒絕買進；股數不足時拒絕賣出。
  - **比較基準**：買進持有在第一個即時交易日開盤的股數與費用正確；定期定額在第 1、21、41… 個即時交易日各投入一次，投完 12 期後停止。
  - **存檔與讀檔**：進行到某個交易日的某個 tick 並有若干交易後存檔，讀回後得到相同的 K 棒、tick 進度、部位、現金、交易紀錄與比較基準數值；引擎版本號不符時拒絕讀檔。
  - **讀檔效能**：30 年存檔在 Node 中重算時間 < 3 秒。
- **測試工具**：Node 內建的 `node:test`，不需要安裝套件。
- **不寫自動化測試的部分**：Canvas 繪圖、縮放平移、觸控手勢、桌面與手機版面、`localStorage` 讀寫時機。這些用瀏覽器人工檢查，手機版用 Chrome 裝置模擬（例如 390×844）。
- **先例**：repo 目前沒有任何測試，本規格建立第一批。

## Out of Scope

- 放空、融資、當沖規則
- 限價單、停損單、掛單簿、滑價
- 漲跌停鎖死（買不到或賣不掉）
- 多檔股票、指數、股利、除權息、公司事件
- KD、MACD 等技術指標
- 多個存檔槽，以及存檔的匯出與匯入
- 雲端同步、帳號、排行榜
- 遊戲結算畫面
- 自動交易策略介面
- 在實體手機上測試（只用瀏覽器裝置模擬）

## Further Notes

- 建議的實作順序：價格引擎（含統計測試）→ 盤中 tick 與 K 棒 → 圖表 → 交易與帳務（含測試）→ 比較基準與資產曲線 → 存檔 → 手機版。
- 用語以 `GLOSSARY.md` 為準：交易日、K 棒、Tick、市場狀態、種子、存檔、市價單、部位、比較基準、買進持有、定期定額、總資產。
- 存檔策略的限制見 `docs/adr/0001-存檔以種子重算行情.md`：任何改動價格引擎亂數使用方式或參數的變更，都必須遞增引擎版本號。
- 模型參數（GARCH、市場狀態切換機率、跳躍機率與幅度）若在實作時發現手感不對，可以在統計測試仍通過的前提下微調，並遞增引擎版本號。
