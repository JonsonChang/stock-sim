# 06: 存檔、讀檔與重新開局

**What to build:** 使用者關掉瀏覽器後再回來，會回到離開時的同一個 tick，並處於暫停狀態，可以接著玩。系統只存種子、開局設定、進度、交易紀錄和介面設定，讀檔時用種子重算行情（見 ADR-0001）。使用者也可以重新開局，改種子、起始價、初始資金，新的一局會覆蓋舊存檔。規格見 `.scratch/stock-sim/spec.md` 和 `docs/adr/0001-存檔以種子重算行情.md`。

**Blocked by:** 02, 03, 05

**Status:** ready-for-agent

- [ ] 模擬核心可以產生存檔資料，內容包括引擎版本號、種子、開局設定、進度（第幾個交易日的第幾個 tick）、交易紀錄
- [ ] 模擬核心可以從存檔還原：用種子重算到同一個 tick，再重放交易紀錄；引擎版本號不符時拒絕
- [ ] 介面設定（速度、比較基準勾選、揭曉開關）一併保存在 `localStorage`，每個瀏覽器只有一份存檔
- [ ] 自動存檔時機：每筆成交後、每個交易日收盤時、`visibilitychange` 或 `pagehide` 發生時
- [ ] 重新開啟時回到同一個 tick，一律處於暫停狀態
- [ ] 版本不符時，頁面內顯示「行情引擎已更新，需重新開局」
- [ ] 「重新開局」按鈕展開設定區（種子、起始價、初始資金），用頁面內的按鈕確認，不使用 `alert` 或 `confirm`；確認後覆蓋存檔；局中不能修改開局設定
- [ ] `node:test` 測試：進行到某個交易日的某個 tick，並有若干筆交易後存檔；讀回後的 K 棒、進度、部位、現金、交易紀錄和比較基準數值都完全相同
- [ ] `node:test` 測試：引擎版本號不符時拒絕讀檔
- [ ] `node:test` 測試：5,000 個交易日的存檔，在 Node 中重算時間 < 1 秒
- [ ] 在瀏覽器中人工檢查：關閉分頁後再開，回到同一個 tick
