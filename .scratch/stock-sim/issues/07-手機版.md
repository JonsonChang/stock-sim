# 07: 手機版

**What to build:** 使用者在手機（寬度 ≤ 768px）上也能完整操作：圖表在上方，中間常駐關鍵數字，底部固定買進／賣出按鈕，其他資訊用分頁切換。圖表支援兩指縮放、單指平移、長按查看 K 棒詳情。規格見 `.scratch/stock-sim/spec.md`。

**Blocked by:** 04, 05

**Status:** done

- [x] 寬度 ≤ 768px 時切換成手機版面：三個圖表窗格約佔畫面上方 55%
- [x] 中間常駐一列，顯示現價、漲跌%、總資產報酬%、速度切換
- [x] 底部固定「買進／賣出」大按鈕，按下後從底部滑出下單面板，面板含股數輸入與快捷鍵
- [x] 部位、績效、交易紀錄改成分頁切換
- [x] 兩指縮放、單指左右拖曳平移，三個窗格同步

- [x] 頁面沒有水平捲動；觸控操作不會誤觸頁面縮放
- [x] 用 Chrome 裝置模擬（390×844）人工檢查以上行為，桌面版的行為不受影響
