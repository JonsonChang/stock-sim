# 02: 市價單交易與帳務

**What to build:** 使用者拿初始資金（預設 100 萬），隨時用市價單買進或賣出，以當下 tick 價全數成交；暫停時也能下單。系統依台股規則計算手續費與證交稅，並即時顯示部位、現金、總資產、損益和交易紀錄，K 線圖上標出買賣點。規格見 `.scratch/stock-sim/spec.md`。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 模擬核心可以對當下 tick 價下市價單（買進或賣出，指定股數），回傳成交結果，或回傳拒絕原因（現金不足、股數不足）
- [ ] 可買零股；下單面板用股數輸入，有「1 張」「全部資金」快捷按鈕，下單前顯示預估成交金額與費用
- [ ] 手續費 0.1425%，最低 20 元，整股和零股一律適用；賣出時另扣證交稅 0.3%
- [ ] 不可放空、不可融資，現金永遠不會變成負數
- [ ] 暫停時下單，以最後一個 tick 價成交；漲跌停時仍可成交
- [ ] 畫面顯示部位股數、平均成本（含買進手續費）、現金、總資產、未實現損益、已實現損益
- [ ] 交易紀錄清單的欄位為交易日、買/賣、股數、成交價、手續費、證交稅，最新的放最上面
- [ ] K 線圖上對應的 K 棒標出買賣點（▲ 買、▼ 賣）
- [ ] `node:test` 測試：買進手續費與最低 20 元、賣出證交稅、一買一賣之後的現金與已實現損益、零股成交、現金不足與股數不足時拒絕
- [ ] `node:test` 測試：在不同時間點下單或完全不下單，行情都完全相同
