# 01: 會動的即時 K 線圖（tracer bullet）

**What to build:** 打開網頁就看到一張會動的 K 線圖。系統用種子產生行情，開局先有 250 個交易日的歷史 K 棒，接著當日的 K 棒隨 tick 即時長出來，下方顯示成交量。使用者可以播放、暫停，並切換 1x、5x、20x 速度，畫面上看得到目前的種子。這張 ticket 先用最簡單的價格模型（GBM＋Student-t），同時建立模擬核心這個唯一的測試接縫，打通「模擬核心 → 介面 → 測試」整條路徑。規格見 `.scratch/stock-sim/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 模擬核心是不碰 DOM 的獨立模組，瀏覽器和 Node 都能載入
- [x] 模擬核心可以用「種子＋開局設定」建立一局、推進一個 tick、讀取 K 棒序列（含正在形成的當日 K 棒）與現價
- [x] 價格模型使用對數報酬加上 Student-t（ν=4，縮放成變異數 1）雜訊，價格永遠為正
- [x] 每個交易日有 270 個 tick，K 棒的開高低收隨 tick 即時更新
- [x] 開局預產 250 個交易日的歷史，起始價 100 元；未指定種子時隨機產生，畫面上顯示目前的種子
- [x] 單一 HTML 頁面用 Canvas 畫出 K 線圖（紅漲綠跌）與成交量，預設跟隨最新的 K 棒
- [x] 有播放、暫停與 1x（10 秒/交易日）、5x（2 秒）、20x（0.5 秒）切換；交易日之間不停頓
- [x] `node:test` 測試：相同種子產生完全相同的行情
- [x] `node:test` 測試：每根 K 棒都滿足 最高 ≥ max(開, 收)、最低 ≤ min(開, 收)，且收盤價等於當日最後一個 tick 價
