# 05: 比較基準與資產曲線

**What to build:** 使用者可以把自己的報酬率和「買進持有」「定期定額」兩個比較基準並列比較，並在 K 線圖與成交量下方的第三個窗格，看到三者的資產曲線隨時間變化。資產曲線和 K 線圖共用時間軸，縮放與平移同步，最右端隨每個 tick 即時更新。規格見 `.scratch/stock-sim/spec.md`。

**Blocked by:** 02, 04

**Status:** done

- [x] 買進持有：在第一個即時交易日開盤，用全部初始資金買進（股數無條件捨去，扣手續費），之後永不賣出
- [x] 定期定額：從第一個即時交易日起，每 20 個交易日以當期第一個交易日的開盤價投入初始資金的 1/12（股數無條件捨去，扣手續費），投完 12 期就停止
- [x] 模擬核心提供使用者與兩個比較基準的報酬率，以及資產曲線（每個交易日的收盤值加上當下的即時值）
- [x] 績效區並列三者的報酬率，每個比較基準都可以勾選要不要顯示
- [x] 第三個窗格畫資產曲線，Y 軸是報酬率 %，從 0% 起算；預產的歷史區段留白；比較基準的線跟著勾選狀態顯示或隱藏
- [x] 三個窗格的縮放、平移、跟隨最新行為一致
- [x] `node:test` 測試：買進持有的股數與費用正確；定期定額在第 1、21、41… 個即時交易日各投入一次，第 12 期之後不再投入
