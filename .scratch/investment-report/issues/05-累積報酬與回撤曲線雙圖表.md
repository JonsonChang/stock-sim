# 05: 累積報酬與回撤曲線雙圖表

**What to build:** 使用者在投資報告中能透過共用時間軸的「累積報酬曲線」與「回撤曲線（水下圖）」兩張圖表，直覺看懂自己與比較基準隨時間的差距及回撤深度與修復過程，並能自由切換比較基準與懸停讀取當日數值。規格見 `.scratch/investment-report/spec.md`。

**Blocked by:** 02: 最大回撤與風險調整指標

**Status:** done

- [x] 模擬核心對外提供與即時交易日對齊的報告曲線序列，每點包含日期與三方（我的操作、買進持有、定期定額）各自之累積報酬率及當下回撤幅度
- [x] 報告內繪製上下同步對齊時間軸之「累積報酬曲線」與「回撤曲線（水下圖）」雙圖表，採與主畫面一致的線條色系
- [x] 報告圖表預設三條線皆開啟，並於圖表區提供報告專用的「買進持有」「定期定額」獨立勾選開關，不影響主畫面之勾選偏好
- [x] 支援桌面滑鼠懸停與手機觸控點按／左右拖曳顯示十字線及該交易日之日期、三方累積報酬率與回撤幅度
- [x] 核心測試驗證報告曲線序列之長度、日期對齊、末點與總覽報酬率／當前回撤一致，且極值涵蓋最大回撤
