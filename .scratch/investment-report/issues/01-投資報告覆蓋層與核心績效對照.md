# 01: 投資報告覆蓋層與核心績效對照

**What to build:** 使用者可在上方資訊列點擊「投資報告」隨時開啟頁內覆蓋層（不用等到 30 年模擬期限），檢視「我的操作」與「買進持有」「定期定額」三欄並排的核心損益、總報酬率與年化報酬率；開啟時自動暫停播放、到達模擬期限時自動彈出一次，桌面與手機皆可完整閱讀。規格見 `.scratch/investment-report/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 上方資訊列新增「投資報告」按鈕，於任何時刻（含尚未交易或交易日盤中）皆可開啟頁內全畫面覆蓋層，按「關閉」或 Esc 鍵回到主畫面
- [ ] 開啟投資報告時若行情正在播放則自動暫停；關閉報告後維持暫停狀態
- [ ] 模擬進行中剛推進至模擬期限那一刻自動開啟一次投資報告；讀檔載入原本已到期的進度時不自動開啟
- [ ] 報告頂部顯示目前情境資訊（種子、起始日期至當下交易日日期、經過模擬年度與交易日數、是否已達模擬期限）
- [ ] 模擬核心對外提供唯讀投資報告查詢介面，並於介面三欄並排呈現「我的操作」「買進持有」「定期定額」之總資產、總損益、總報酬率與年化報酬率
- [ ] 年化報酬率以「起始日期至當下交易日之日曆天數 ÷ 365.25」計算複利報酬；經過未滿 20 個交易日時顯示 `—` 並附上簡短說明
- [ ] 核心績效區列出「我的操作」之已實現損益、未實現損益、累計手續費與累計證交稅，盤中隨當下 tick 即時納入計算
- [ ] 手機版（螢幕寬度 ≤ 768px）覆蓋層支援順暢垂直捲動且對照表格不擠壓破版
- [ ] 保持既有存檔結構與引擎版本號不變，舊存檔可直接讀取使用
- [ ] 核心測試涵蓋：0 筆交易與早期未滿 20 個交易日門檻、盤中即時反映未實現損益、滿 20 個交易日後年化報酬率手算比對、存檔重算後報告一致，且既有測試全數通過
