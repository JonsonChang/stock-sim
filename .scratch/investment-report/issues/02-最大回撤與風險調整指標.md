# 02: 最大回撤與風險調整指標

**What to build:** 使用者在投資報告中能看到「我的操作」與「買進持有」「定期定額」三方並排的最大回撤（含波峰日、波谷日、恢復日或「尚未恢復」與當前回撤）、年化波動率、夏普比率與卡瑪比率，完整評估報酬背後的風險承受程度。規格見 `.scratch/investment-report/spec.md`。

**Blocked by:** 01: 投資報告覆蓋層與核心績效對照

**Status:** done

- [x] 模擬核心依「開局初始資金（報酬率 0%，日期為起始日期）＋每個已收盤即時交易日＋當下即時點」的總資產序列，分別計算三方的最大回撤與當前回撤幅度
- [x] 最大回撤附上波峰日期、波谷日期，以及首次回到或超越該波峰的恢復日期（尚未創高時顯示「尚未恢復」）
- [x] 計算三方年化波動率（每日總資產報酬率之樣本標準差 × √260）、夏普比率（無風險利率 0%）與卡瑪比率（年化報酬率 ÷ |最大回撤|）
- [x] 當即時交易日少於 5 個交易日，或波動率、最大回撤、年化報酬率無法定義時，對應指標安全回傳空值並於介面顯示 `—`（不出現 `NaN` 或 `Infinity`）
- [x] 報告總覽表三欄並排呈現上述最大回撤、區間日期、當前回撤、年化波動率、夏普比率與卡瑪比率
- [x] 核心測試涵蓋：自開局 0% 起算之單調下跌、先漲後跌再創新高（驗證恢復日與當前回撤歸零）、尚未恢復情境、獨立手算驗證波動率／夏普／卡瑪、零波動與不足 5 日邊界
