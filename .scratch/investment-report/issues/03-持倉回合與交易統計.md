# 03: 持倉回合與交易統計

**What to build:** 使用者在投資報告中能檢視自己的交易習慣與操作品質，依完整的「持倉回合」（從空手買進到全數賣出歸零）統計勝率、賺賠比、最大單回合盈虧與平均持有交易日數，並在仍有未清倉部位時獨立顯示進行中部位狀態。規格見 `.scratch/investment-report/spec.md`。

**Blocked by:** 01: 投資報告覆蓋層與核心績效對照

**Status:** ready-for-agent

- [ ] 模擬核心統計總買進次數與總賣出次數，並依「部位股數從 0 買進至全數賣出歸零」切分已完結持倉回合
- [ ] 計算並顯示已完成持倉回合數、勝率（獲利回合數 ÷ 已完成回合數）、賺賠比（獲利回合平均獲利 ÷ |虧損回合平均虧損|）、單筆回合最大獲利、單筆回合最大虧損與平均持有交易日數
- [ ] 當尚未有任何已完成持倉回合（或全贏／全輸導致賺賠比無虧損分母）時，對應統計顯示 `—` 並標註僅計入已完成回合
- [ ] 當下部位股數大於 0 時，獨立顯示「進行中部位狀態」（部位股數、已持有交易日數、現行回合已實現損益與當下未實現損益）
- [ ] 核心測試涵蓋：單回合完整買賣、分批加碼與部分減碼（驗證未歸零前不計入已完成勝率且進行中狀態正確）、多回合勝率／賺賠比與持有交易日數計算
