# 投資報告

Status: ready-for-agent

## Problem Statement

在模擬過程中與到達模擬期限時，目前的畫面只有當下的部位損益、總報酬率與陽春的資產曲線，缺乏完整的投資報告頁面。我無法評估自己操作所承擔的風險（例如最大回撤與波動率）、無法換算年化報酬率與風險調整後績效，也不知道自己交易的勝率、賺賠比與持有天數表現如何，更無法用同一套嚴謹口徑與「買進持有」「定期定額」兩個比較基準並排比較。此外，這份評估必須在模擬進行中的任何時刻都能隨時查看，而不必等到 30 年模擬期限到達才能結算。

## Solution

在現有單頁介面內新增可隨時開啟與關閉的「投資報告」覆蓋層頁面，並於模擬進行中到達模擬期限的那一刻自動彈出一次。報告以截至當下 tick 的即時總資產（含未實現損益）為準，將「我的操作」與「買進持有」「定期定額」三欄並排呈現損益、總報酬率、年化報酬率、最大回撤（含波峰、波谷與恢復日期）、年化波動率、夏普比率與卡瑪比率；同時提供依完整持倉回合計算的交易統計（勝率、賺賠比、單筆回合最大獲利與虧損、平均持有交易日數、交易費用與進行中部位狀態）、依模擬年度切分的分年報酬明細，以及同步對齊時間軸的「累積報酬曲線」與「回撤曲線（水下圖）」雙圖表。

## User Stories

### 開啟與生命週期

1. As a 使用者, I want 在上方資訊列點擊「投資報告」按鈕隨時打開報告頁面, so that 我不用等到 30 年模擬期限就能評估目前表現。
2. As a 使用者, I want 剛開局還沒成交任何一筆市價單、或正處於交易日盤中時也能打開投資報告, so that 報告在任何時刻都可用。
3. As a 使用者, I want 開啟投資報告時若行情正在播放則自動暫停, so that 我閱讀數據時數字不會一直跳動、也不會漏看盤勢。
4. As a 使用者, I want 關閉投資報告後維持暫停並立即回到原本看盤位置, so that 我能先檢視 K 線圖再自行決定何時按播放繼續。
5. As a 使用者, I want 在模擬進行中剛推進到 30 年模擬期限時自動開啟一次投資報告, so that 我能直接看到整局的完整總結，且關閉後仍可回頭檢視圖表或重新開局。
6. As a 使用者, I want 載入一份原本就已到達模擬期限的存檔時停留在主畫面，不自動彈出報告, so that 我重新開啟網頁想回顧 K 線圖時不會被蓋住。

### 核心績效與比較基準對照

7. As a 使用者, I want 在投資報告中看到「我的操作」與「買進持有」「定期定額」三欄並排的績效總覽, so that 我能客觀對比主動操作與被動比較基準的優劣。
8. As a 使用者, I want 看到累計投入本金（含初始資金與累計每月入金）、當下總資產、總損益、已實現損益、未實現損益與總報酬率（累計投入報酬率）, so that 在每月持續入金下仍能掌握目前實際賺賠與資產變化。
9. As a 使用者, I want 看到三方的年化報酬率（依起始日期至當下經過的日曆天數除以 365.25 年化）, so that 我能跨不同模擬長度比較長期複合報酬。
10. As a 使用者, I want 在經過時間未滿 20 個交易日時年化報酬率顯示「—」並標示原因, so that 剛開局幾天的短期報酬不會被公式極端放大誤導判讀。
11. As a 使用者, I want 看到自己累計支付的手續費與證交稅總額, so that 我清楚交易摩擦成本對報酬的影響。

### 風險與最大回撤

12. As a 使用者, I want 看到三方各自的最大回撤幅度（從歷史波峰到後續波谷的最大跌幅比例）, so that 我知道過程中曾承受多大的帳面虧損壓力。
13. As a 使用者, I want 看到最大回撤發生的波峰日期、波谷日期與恢復創高日期（若尚未創新高則顯示「尚未恢復」）, so that 我知道回撤何時發生、拖了多久才回本。
14. As a 使用者, I want 看到目前總資產距離歷史高點的當前回撤幅度, so that 我知道當下是否仍處於回撤區間。
15. As a 使用者, I want 最大回撤將起始基準點（報酬率 0%）作為歷史波峰的起算基準, so that 即使從第一個即時交易日起就一路虧損也能正確算出最大回撤。
16. As a 使用者, I want 看到三方的年化波動率、夏普比率（無風險利率 0%）與卡瑪比率, so that 我能從風險調整後報酬的角度比較績效。
17. As a 使用者, I want 在交易日資料不足（少於 5 個交易日）或波動率／最大回撤為零時，對應風險指標顯示「—」, so that 畫面不會出現無意義或錯誤數值。

### 交易統計與持倉回合

18. As a 使用者, I want 看到總買進次數與總賣出次數, so that 我知道自己的交易頻繁程度。
19. As a 使用者, I want 系統將從空手買進到全數賣出歸零定義為一個「持倉回合」，據此統計已完成回合數、勝率與賺賠比, so that 分批進出不會虛增交易筆數或扭曲勝率。
20. As a 使用者, I want 看到已完結持倉回合的單筆回合最大獲利、單筆回合最大虧損與平均持有交易日數, so that 我能檢視極端盈虧與操作週期特性。
21. As a 使用者, I want 當目前仍有部位未全數賣出時，獨立看到「進行中部位狀態」（股數、已持有交易日數、現行回合已實現損益與當下未實現損益）, so that 我不會誤以為部分賣出的損益被遺漏。
22. As a 使用者, I want 在尚未有任何已完結持倉回合時，勝率、賺賠比等統計顯示「—」並說明僅計入已完結回合, so that 意義清楚不誤導。

### 分年報酬明細與報告圖表

23. As a 使用者, I want 看到依「模擬年度」（第 1 年、第 2 年…）切分的分年報酬明細表，含該年度起訖日期與三方報酬率, so that 我能與上方資訊列的第 N 年對照並檢視各年度表現。
24. As a 使用者, I want 尚未滿一年的當前模擬年度照常顯示「累計至今」的當年度報酬率, so that 隨時打開報告都能看到今年以來的進度。
25. As a 使用者, I want 在報告內看到「累積報酬曲線」與下方對齊的「回撤曲線（水下圖）」兩張圖表, so that 我能直覺看出何時拉開差距以及回撤深度與修復過程。
26. As a 使用者, I want 報告圖表預設同時顯示「我的操作」「買進持有」「定期定額」三條線，且可在報告內獨立勾選切換（不影響主畫面勾選狀態）, so that 我能自由聚焦比較對象。
27. As a 使用者, I want 在報告圖表上移動滑鼠（或手機點按）顯示十字線與該交易日的日期、三方累積報酬率與當下回撤幅度, so that 我能查看任意時間點的精確數據。

### 手機版

28. As a 手機使用者, I want 投資報告覆蓋層在小螢幕下可順暢上下捲動閱讀卡片、圖表與表格, so that 手機上也能完整檢視所有評估數據。
29. As a 手機使用者, I want 報告內的對照表格在窄螢幕下保持欄位清楚不破版, so that 三方數值對照容易閱讀。

## Implementation Decisions

- **架構與既有決策相容性**：
  - 投資報告的所有指標與圖表序列皆可由現有的每日資產曲線、交易紀錄、每日 K 棒日期與起始日期即時推算，因此**不修改行情亂數、不變更存檔格式、不需遞增引擎版本號**，舊存檔可直接開啟使用，亦完全維持既有「存檔以種子重算行情」的架構決策。
  - 本規格將先前列為未實作範圍的「到達模擬期限後之結算檢視」正式納入為隨時與到期皆可用的「投資報告」功能。
- **測試接縫與模擬核心（headless）新增責任**：
  - 沿用唯一的測試接縫（模擬核心），由核心對外提供取得完整投資報告資料的唯讀查詢介面，不新增額外接縫。
  - **損益與報酬計算**：
    - 總損益等於當下總資產減去各自之累計投入本金（使用者方亦等於已實現損益加上未實現損益）；累計手續費與累計證交稅分別加總全部成交紀錄。
    - 總報酬率採累計投入報酬率（當下總資產 − 累計投入本金）÷ 累計投入本金（累計投入本金為 0 時回傳 0；見 ADR-0002）。
    - 年化報酬率（CAGR）以起始日期（第一個即時交易日）至當下交易日所經過的日曆天數除以 365.25 作為年數；當已進行的即時交易日數少於 20 個交易日（或當下總資產 ≤ 0）時回傳空值（介面顯示 `—`）。
  - **總資產序列與最大回撤**：
    - 序列由「起始基準點（以開局設定與各比較基準起點為準，報酬率 0%、日期為起始日期）」接續「每個已收盤即時交易日」與「當下即時點（若當日尚未收盤）」組成；使用者與兩個比較基準（買進持有、定期定額）各自依其總資產／累計投入本金狀態套用一致的計算公式。
    - 逐點維護歷史最高點，回撤 =（當下總資產 − 歷史最高點）÷ 歷史最高點（≤ 0）。最大回撤取序列中最小值（最深跌幅），記錄波峰日（取創下該高點並隨後跌出最大回撤的起始高點日）、波谷日與恢復日（該波谷之後首次回到或超越該波峰的交易日；若尚未回到則為空值），並同時提供最後一點的當前回撤幅度。
  - **年化波動率與風險調整比率**：
    - 日報酬率序列由各相鄰交易日（從開局 0% 至第 1 個即時交易日、以及後續相鄰即時交易日）之日報酬構成；當交易日數少於 5 個交易日時，年化波動率、夏普比率與卡瑪比率皆回傳空值。
    - 年化波動率 = 日報酬率之樣本標準差 × √260（對應週一至週五皆開盤之年交易日結構）。
    - 夏普比率 = 年化報酬率 ÷ 年化波動率（無風險利率採 0%）；當波動率為 0 或年化報酬率為空值時回傳空值。
    - 卡瑪比率 = 年化報酬率 ÷ |最大回撤|；當最大回撤為 0 或年化報酬率為空值時回傳空值。
  - **持倉回合統計**：
    - 逐筆掃描交易紀錄：當部位股數從 0 變為正數時開啟一個新回合（記錄進場交易日索引與當日累計手續費、買進總成本）；回合進行期間若有加碼或部分賣出，持續累計該回合的買進成本、賣出淨收款與已實現損益；當部位股數回到 0 時完結該回合（記錄出場交易日索引、持有交易日數 = 出場交易日索引 − 進場交易日索引 + 1、回合淨損益 = 賣出淨收款總和 − 買進成本總和）。
    - 勝率 = 回合淨損益 > 0 的已完結回合數 ÷ 總已完結回合數；賺賠比 = 獲利已完結回合平均獲利金額 ÷ |虧損已完結回合平均虧損金額|（若無獲利或無虧損回合則回傳空值）。
    - 若當下部位股數大於 0，另外輸出進行中回合摘要（持有股數、已持有交易日數 = 當下交易日索引 − 進場交易日索引 + 1、該回合已部分賣出之已實現損益、當下未實現損益）。
  - **分年報酬明細**：
    - 依模擬年度（從起始日期起算，每滿一個日曆年為一年度）將即時交易日分組，每列提供年度編號（第 N 年）、涵蓋起訖日期、是否為進行中年度，以及該年度三方各自之區間報酬率（依累計投入本金口徑與對應資產變化計算，見 `.scratch/monthly-contribution/spec.md` 與 ADR-0002）。
  - **圖表序列輸出**：
    - 提供與即時交易日對齊的每日點陣列（含日期、三方累積報酬率與三方當下回撤幅度），供介面層繪製報告雙圖表。
- **介面層呈現與互動**：
  - 上方資訊列於「重新開局」旁新增「投資報告」按鈕；點擊開啟頁內全畫面覆蓋層（桌面與手機共用同一套報告視圖），按「關閉」或 Esc 鍵可回到主畫面。
  - 開啟報告時若模擬正在播放，自動暫停播放；關閉報告後維持暫停狀態。
  - 於即時推進迴圈中偵測模擬狀態從「未到期」首次進入「已達模擬期限」時，自動打開一次投資報告；讀檔載入原本即已到期的進度時，不自動打開。
  - 報告版面由上而下分為四區：
    1. **摘要 header 與情境資訊**（種子、起始日期至目前日期、經過模擬年度與交易日數、是否已達模擬期限、關閉按鈕）。
    2. **核心績效總覽表**（我的操作、買進持有、定期定額三欄並排，呈現總資產、總損益、總報酬率、年化報酬率、最大回撤與波峰→波谷→恢復日、當前回撤、年化波動率、夏普比率、卡瑪比率；另列我的已實現損益、未實現損益與累計手續費／證交稅）。
    3. **累積報酬曲線與回撤曲線（水下圖）雙圖表**（共用同一條時間軸於同一組或上下對齊 Canvas 繪製，提供報告內獨立的買進持有／定期定額顯示勾選，支援滑鼠移動與手機觸控點按／拖曳顯示十字線與當日三方數值）。
    4. **交易統計與分年報酬明細**（已完成回合統計、進行中部位狀態列、以及模擬年度分年報酬對照表）。
  - 手機版（螢幕寬度 ≤ 768px）覆蓋層支援垂直捲動，對照表格可橫向捲動或維持緊湊排版以避免字體擠壓破版。

## Testing Decisions

- **好的測試只驗證外部行為**：一律透過模擬核心的公開介面（建立一局、推進 tick、委託市價單、讀取投資報告）驗證輸出結果，不測試內部輔助函式，並以固定種子確保結果可重現。
- **唯一測試接縫**：沿用現有的模擬核心（headless 模組），不新增其他接縫。
- **測試涵蓋行為**：
  - **早期與空手邊界**：開局第 0 天未推進、第 1 天未滿門檻時，年化報酬率（< 20 個交易日）、波動率／夏普／卡瑪（< 5 個交易日）與勝率／賺賠比（0 已完結回合）正確回傳空值；總資產、損益與總報酬率為正確數值。
  - **盤中即時反應**：交易日推進數個 tick 且持有部位時，未實現損益、總資產、總報酬率與當日回撤即時反映當下 tick 價。
  - **年化報酬率**：滿 20 個交易日後依經過日曆天數 ÷ 365.25 套用複利公式與獨立手算相符。
  - **最大回撤與恢復**：在已知價格序列中驗證包含開局 0% 基準的單調下跌、先漲後跌再創高（正確記錄波峰日、波谷日、恢復日，且當前回撤歸零）、以及尚未恢復情境。
  - **波動率、夏普與卡瑪比率**：用已知日報酬序列對照獨立手算之樣本標準差 × √260 與比率；零波動或零回撤時安全回傳空值而不出現 `NaN` 或 `Infinity`。
  - **持倉回合統計**：單筆買賣、分批買進後部分賣出（驗證該筆不計入已完結回合且進行中部位摘要正確）、完整清倉歸零後再開第二回合，驗證回合數、勝率、賺賠比、最大獲利／虧損與平均持有交易日數。
  - **比較基準一致性**：驗證買進持有與定期定額同樣套用相同公式計算最大回撤、年化報酬率、波動率與分年報酬明細。
  - **模擬年度切分**：跨越多個模擬年度（含未滿一年的當前年度），各年度報酬率連乘應等於累積總報酬率。
  - **存檔重算一致性**：存檔並以種子重算讀回後，取得的投資報告數據與讀檔前完全一致。
- **測試先例與工具**：沿用 Node 內建的 `node:test` 與現有的模擬核心測試檔作為先例。
- **手動驗證項目**：覆蓋層開關、開啟時自動暫停、模擬期限到期自動彈出（及讀檔已到期不自動彈出）、報告雙圖表繪製與十字線讀取、報告獨立比較基準勾選、以及手機版（Chrome 裝置模擬 390×844）排版與觸控檢視，維持以瀏覽器人工驗證。

## Out of Scope

- 獨立的外部 HTML 頁面（例如另開分頁顯示報告）
- 匯出報告為 PDF、CSV、PNG 或列印樣式
- 讓使用者自訂無風險利率、年化門檻天數或交易日年化係數
- 依西曆年份（1 月至 12 月）或逐月切分報酬明細表
- 更改交易帳務模式為先進先出（FIFO）或後進先出（LIFO）
- 變更行情模型或存檔格式
