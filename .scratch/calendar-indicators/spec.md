# 日曆日期、K 棒週期與技術指標

Status: ready-for-agent

## Problem Statement

目前的模擬器只知道「第幾個交易日」，看盤時我不知道現在是哪一年、哪一月、星期幾，也沒辦法像真實看盤軟體一樣切換日 K、週 K、月 K 看長期趨勢。沙盒沒有終點，我無法用「一段固定期間」衡量自己的操作成果。另外，原本刻意不提供均線與 KD，但我想練習把常見的技術指標和價格一起判讀，現在只能靠目測。

## Solution

每個交易日對應一個日曆日期（只跳過週六、週日），畫面隨時顯示目前日期與第幾年。使用者可以在圖表左上角切換日 K、週 K、月 K，三個圖表窗格同步改用該 K 棒週期。新增兩個預設關閉的技術指標開關：均線（5、20、60）疊在 K 線圖上，KD(9,3,3) 顯示在獨立窗格；兩者都以目前的 K 棒週期為單位計算，並隨 tick 即時更新。一局最多進行 30 年（模擬期限），到期後行情停止、不能再下單，但仍可檢視圖表與績效，或重新開局。

## User Stories

### 日曆日期

1. As a 使用者, I want 每個交易日對應一個日曆日期, so that 我知道目前是哪一天。
2. As a 使用者, I want 週六、週日不是交易日, so that 日期排列接近真實市場。
3. As a 使用者, I want 國定假日照常是交易日, so that 規則單純、每年交易日數一致。
4. As a 使用者, I want 在開局設定中指定起始日期（第一個即時交易日）, so that 我可以決定這一局從哪一天開始。
5. As a 使用者, I want 起始日期預設為開局當天的真實日期、遇週末順延到下週一, so that 不設定也能直接開始。
6. As a 使用者, I want 開局預產的 250 個交易日歷史從起始日期往前倒推, so that 歷史 K 棒也有正確的日期。
7. As a 使用者, I want 起始日期在局中無法修改, so that 一局的條件從頭到尾一致。
8. As a 使用者, I want 在行情資訊區看到目前日期（例如「2031/03/14（五）」）與「第 N 年」, so that 我隨時知道進度。
9. As a 手機使用者, I want 常駐資訊列也顯示目前日期與第幾年, so that 不切分頁也知道進度。
10. As a 使用者, I want 圖表下緣有日期刻度, so that 我能對照 K 棒的時間位置。
11. As a 使用者, I want 滑鼠移過或長按日 K 時，提示框顯示該交易日的日期, so that 我能查看精確時間。
12. As a 使用者, I want 交易紀錄的交易日欄位顯示日期, so that 我能對照自己在什麼時候買賣。

### 模擬期限

13. As a 使用者, I want 一局最多進行 30 年（從第一個即時交易日起算，不含預產歷史）, so that 練習有明確的期間。
14. As a 使用者, I want 在起始日期滿 30 年的前一個交易日收盤時到期, so that 期限的時間點明確。
15. As a 使用者, I want 到期後行情自動暫停、播放鍵停用, so that 行情不會超過期限。
16. As a 使用者, I want 到期後顯示「已達模擬期限」, so that 我知道為什麼不能繼續播放。
17. As a 使用者, I want 到期後不能再下單, so that 期限之後無法調整部位而影響績效比較。
18. As a 使用者, I want 到期後仍可縮放、平移圖表並查看部位、績效、交易紀錄, so that 我能完整檢討這一局。
19. As a 使用者, I want 到期後仍可重新開局, so that 我能開始下一局。
20. As a 使用者, I want 到期的狀態也能存檔與讀回, so that 回來時看到的仍是到期的那一局。

### K 棒週期

21. As a 使用者, I want 在圖表左上角用分段按鈕切換日 K、週 K、月 K, so that 我能在短線與長期之間切換。
22. As a 手機使用者, I want 手機版也有同樣的週期切換按鈕, so that 手機也能切換。
23. As a 使用者, I want 週 K 由同一週（週一到週五）的交易日組成，跨月的週不拆開, so that 週 K 和看盤軟體一致。
24. As a 使用者, I want 月 K 由同一個日曆月的交易日組成, so that 月 K 和看盤軟體一致。
25. As a 使用者, I want 週 K、月 K 的開盤是期間第一個交易日的開盤、收盤是最後一個交易日的收盤、高低是期間極值、量是加總, so that 數字符合慣例。
26. As a 使用者, I want 正在進行中的那一週或那一月的 K 棒隨 tick 即時長出來, so that 週 K、月 K 也能看即時行情。
27. As a 使用者, I want 預產歷史最前面不滿一週或一月時，照樣畫出不完整的那根 K 棒, so that 歷史資料不會被丟掉。
28. As a 使用者, I want 切換週期時，若原本在跟隨最新就繼續跟隨最新, so that 不必再按「回到最新」。
29. As a 使用者, I want 切換週期時，若原本平移在看歷史，畫面右緣停在同一個日期, so that 我不會失去正在看的位置。
30. As a 使用者, I want 切換週期時可視根數換算成接近的時間長度（並限制在 20 根到全部之間）, so that 切換前後看到的時間範圍差不多。
31. As a 使用者, I want 滑鼠移過或長按週 K、月 K 時，提示框顯示「起日–迄日」與開高低收、成交量, so that 我知道這根 K 棒涵蓋的期間。
32. As a 使用者, I want 週 K、月 K 期間內有買進就在 K 棒下方標 ▲、有賣出就在上方標 ▼（兩者都有就都標）, so that 我在長週期也看得到進出場。
33. As a 使用者, I want 週 K、月 K 的提示框列出這段期間的買進與賣出筆數, so that 我知道標記背後有幾筆交易。
34. As a 使用者, I want 資產曲線跟著目前的週期取點（一根 K 棒一點，用期末交易日收盤值，最右點即時更新）, so that 資產曲線與 K 線圖的 X 軸一一對齊。
35. As a 使用者, I want 開啟揭曉時，市場狀態背景帶仍以交易日為單位畫在 K 棒寬度內, so that 一根週 K 裡換了狀態也看得出來。
36. As a 使用者, I want 開啟揭曉時，週 K、月 K 期間內任一天有跳躍就在該 K 棒上方標記, so that 我知道哪些長週期的大波動含跳躍。
37. As a 使用者, I want 目前選的週期寫進存檔, so that 回來時畫面和離開時一致。

### 均線

38. As a 使用者, I want 一個預設關閉的「均線」開關, so that 平時仍可練習直接閱讀價格。
39. As a 使用者, I want 開啟均線後 K 線圖上疊加 5、20、60 三條均線, so that 我能看出短中長期趨勢。
40. As a 使用者, I want 均線以目前 K 棒週期的「根」為單位計算（週 K 的 20 均線就是 20 週均線）, so that 和看盤軟體一致。
41. As a 使用者, I want 正在形成的最後一根 K 棒用當下 tick 價即時計算均線, so that 均線和價格同步。
42. As a 使用者, I want K 棒數不足 N 根時不畫該條均線, so that 不會出現用不足資料算出的誤導數值。
43. As a 使用者, I want 三條均線用中性、不和紅漲綠跌衝突的顏色，並有圖例顯示目前數值, so that 我分得出是哪一條、數值多少。
44. As a 使用者, I want 均線開關狀態寫進存檔, so that 回來時設定不變。

### KD

45. As a 使用者, I want 一個預設關閉的「KD」開關, so that 平時仍可練習直接閱讀價格。
46. As a 使用者, I want 開啟 KD 後在成交量與資產曲線之間出現 KD 窗格, so that 我能對照 KD 與價格。
47. As a 使用者, I want KD 採台股慣例 KD(9,3,3)：RSV 取 9 根、K 與 D 各以 1/3 平滑、初始值 50, so that 數值和看盤軟體一致。
48. As a 使用者, I want KD 以目前 K 棒週期為單位計算並隨 tick 即時更新, so that 切換週期後 KD 也跟著變。
49. As a 使用者, I want KD 窗格畫出 20 與 80 兩條參考線, so that 我能判斷超買超賣區。
50. As a 使用者, I want KD 窗格和其他窗格共用時間軸，縮放、平移同步, so that 我能逐根對照。
51. As a 使用者, I want 關閉 KD 時整個窗格隱藏、空間還給 K 線圖, so that 不用的時候圖表更大。
52. As a 手機使用者, I want 開啟 KD 時四個窗格仍約佔畫面上方 55%, so that 手機版面不被擠壞。
53. As a 使用者, I want 滑鼠移過或長按時，提示框也顯示該 K 棒的均線與 K、D 值（指標開啟時）, so that 我能查看精確數值。
54. As a 使用者, I want KD 開關狀態寫進存檔, so that 回來時設定不變。

### 存檔

55. As a 使用者, I want 30 年的存檔也能在 3 秒內讀檔完成，並在讀取時看到「讀取中…」, so that 長局也不用久等、也知道程式沒當掉。
56. As a 使用者, I want 舊版存檔讀取時看到「行情引擎已更新，需重新開局」, so that 不會讀到缺少日期資料的存檔。

## Implementation Decisions

- **推翻的既有決定**（`.scratch/stock-sim/spec.md`）：
  - Story 18「沙盒沒有終點」改為 30 年模擬期限。
  - Story 27「圖表上不出現均線等技術指標」刪除；Out of Scope 中的「均線、KD」與「固定局數」移除（MACD 等其他指標仍不做）。
  - 讀檔效能由「5,000 個交易日 < 1 秒」改為「30 年存檔 < 3 秒」。實測 30 年（約 7,830 個即時交易日）重算約 1.8 秒。
  - 行情仍完全由種子決定，ADR-0001 不變；日期只是交易日索引的對應，不使用亂數。
- **模擬核心（headless）新增責任**，全部透過既有的唯一測試接縫對外提供：
  - **日期**：以起始日期（第一個即時交易日）為錨點，每個交易日索引對應一個日曆日期，跳過週六、週日；預產歷史往前倒推。起始日期是開局設定的一部分，和種子、起始價、初始資金並列；起始日期若落在週末，核心順延到下週一。
  - **K 棒週期聚合**：讀取狀態時可指定 K 棒週期（日 K、週 K、月 K），回傳該週期的 K 棒序列。每根聚合 K 棒帶有起日與迄日、所涵蓋的交易日索引範圍，正在形成的最後一根以當下 tick 即時更新。週以週一到週五分組，月以日曆月分組。
  - **技術指標**：依指定 K 棒週期回傳每根 K 棒的均線（5、20、60）與 K、D 值；不足 N 根的均線為空值。KD(9,3,3)：RSV = (收盤 − 9 根最低) / (9 根最高 − 9 根最低) × 100，K = 2/3 × 前 K + 1/3 × RSV，D = 2/3 × 前 D + 1/3 × K，第一根之前的 K、D 為 50；高低相等時 RSV 取 50（避免除以零）。
  - **資產曲線**：可依 K 棒週期取點，每根 K 棒一點，取期末交易日收盤值，最後一點是當下即時值；預產歷史區段仍留白。
  - **模擬期限**：到期日為起始日期滿 30 年的前一個交易日。該交易日收盤後，推進 tick 不再改變行情，下單一律拒絕並回傳「已達模擬期限」的拒絕原因。讀取狀態可得知是否已到期。
  - 週 K、月 K 上的買賣標記、跳躍標記與市場狀態背景帶，由介面層利用聚合 K 棒的交易日索引範圍，搭配既有的交易紀錄與每日市場狀態／跳躍標記組出，核心不另外提供聚合版本。
- **存檔**：
  - 存檔新增起始日期（屬於開局設定）。
  - 介面設定新增目前的 K 棒週期、均線開關、KD 開關，和既有的速度、比較基準勾選、揭曉開關一起保存。
  - 遞增引擎版本號，舊存檔沿用既有的「行情引擎已更新，需重新開局」提示，不寫遷移。
  - 讀檔時顯示「讀取中…」。
- **介面層**：
  - 圖表左上角放日 K／週 K／月 K 分段按鈕（桌面與手機相同）。
  - 「均線」「KD」兩個開關放在揭曉開關旁，預設關閉。
  - 窗格由上而下：K 線、成交量、KD（開啟時才出現）、資產曲線；所有窗格共用時間軸，縮放、平移同步。
  - 均線用三種中性色，K 線圖角落有圖例顯示三條均線目前數值；KD 窗格畫出 20、80 參考線。
  - 圖表下緣顯示日期刻度。
  - 行情資訊區與手機常駐資訊列顯示「YYYY/MM/DD（週）」與「第 N 年」。
  - 提示框：日 K 顯示單一日期；週 K、月 K 顯示起日–迄日與期間內買進、賣出筆數；指標開啟時一併顯示均線與 K、D 值。
  - 交易紀錄的交易日欄位改為顯示日期。
  - 切換週期：跟隨最新時維持跟隨；平移中時以右緣日期為錨點；可視根數依時間長度換算並限制在 20 根到全部。
  - 開局設定區新增「起始日期」欄位，預設開局當天的真實日期。
  - 到期後：自動暫停、停用播放鍵與速度切換、停用下單按鈕，顯示「已達模擬期限」；圖表互動、面板檢視與重新開局照常可用。
- **定期定額**維持「每 20 個交易日」，不改成每月第一個交易日。

## Testing Decisions

- **好的測試只驗證外部行為**：一律透過模擬核心的公開介面（建立一局、推進 tick、下單、讀取狀態、存檔與讀檔）測試，不測內部函式。使用固定種子，結果才能重現。
- **測試接縫**：沿用唯一的接縫，也就是模擬核心。日期、聚合、指標、模擬期限都在核心內，不新增接縫。
- **要測的行為**：
  - **日期**：連續交易日的日期遞增且沒有週六、週日；第一個即時交易日等於起始日期；起始日期落在週末時順延到下週一；預產歷史的最後一天是起始日期前一個平日。
  - **週 K、月 K 聚合**：開盤、收盤、最高、最低、成交量符合定義；同一週跨月時屬於同一根週 K；月 K 以日曆月分組；盤中最後一根聚合 K 棒隨 tick 更新，且收盤等於當下 tick 價；所有聚合 K 棒的交易日範圍不重疊、首尾相接、涵蓋全部交易日。
  - **均線**：在已知 K 棒序列上數值正確；不足 N 根時為空值；週 K 的均線以週 K 收盤計算。
  - **KD**：用固定種子與手算（或獨立實作）比對數值；第一根之前以 50 起算；高低相等時不出現 NaN。
  - **資產曲線取點**：週 K、月 K 模式下點數等於即時區段的聚合 K 棒數，每點等於期末交易日收盤值，最後一點等於當下即時值。
  - **模擬期限**：推進到到期日收盤後，再推進 tick 不改變 K 棒與進度；下單被拒絕並回傳期限原因；到期狀態存檔後讀回仍為到期。
  - **存檔與讀檔**：起始日期可讀回並得到相同的日期序列；引擎版本號不符時拒絕讀檔。
  - **讀檔效能**：30 年存檔在 Node 中重算 < 3 秒。
  - 既有的行情統計、K 棒合法性、決定性、帳務、比較基準測試全部維持通過。
- **測試工具**：Node 內建的 `node:test`，沿用既有的模擬核心測試檔作為先例。
- **不寫自動化測試的部分**：週期切換按鈕、指標開關、KD 窗格版面、日期刻度、提示框內容、切換週期時的視窗錨定、到期後按鈕停用、手機版四窗格佈局。這些用瀏覽器人工檢查，手機版用 Chrome 裝置模擬（例如 390×844）。

## Out of Scope

- 台股國定假日與休市日
- 均線週期、KD 參數由使用者自訂
- MACD、RSI、布林通道等其他技術指標
- 年 K、分 K 等其他 K 棒週期
- 定期定額改為每月投入
- 到期後的結算畫面
- 舊版存檔遷移
- 延長或自訂模擬期限
- 顯示剩餘年數

## Further Notes

- 用語以 `GLOSSARY.md` 為準，本次新增或更新：交易日、K 棒、K 棒週期、模擬期限、技術指標、均線、KD。注意「週線、月線」在台股指均線，K 棒週期一律稱「週 K、月 K」。
- 建議實作順序：日曆日期與模擬期限 → K 棒週期切換（含資產曲線取點、標記聚合）→ 均線與 KD。
- 實作時應同步更新 `.scratch/stock-sim/spec.md` 中被推翻的 Story 18、27、Out of Scope 與讀檔效能條目，避免兩份規格互相矛盾。
