# 01: 日曆日期

**What to build:** 每個交易日對應一個日曆日期（只跳過週六、週日），使用者隨時知道目前是哪一天、第幾年。開局時可以指定起始日期（第一個即時交易日），預產的歷史往前倒推。規格見 `.scratch/calendar-indicators/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 模擬核心為每個交易日提供日曆日期；連續交易日的日期遞增且沒有週六、週日，國定假日照常是交易日
- [ ] 起始日期是開局設定的一部分（和種子、起始價、初始資金並列）；落在週末時順延到下週一
- [ ] 第一個即時交易日等於起始日期；預產歷史的最後一天是起始日期前一個平日
- [ ] 開局設定區新增「起始日期」欄位，預設為開局當天的真實日期，局中無法修改
- [ ] 桌面行情資訊區與手機常駐資訊列顯示「YYYY/MM/DD（週）」與「第 N 年」
- [ ] 滑鼠移過或長按 K 棒時，提示框顯示該交易日的日期
- [ ] 交易紀錄的交易日欄位顯示日期
- [ ] 圖表下緣顯示日期刻度
- [ ] 起始日期寫進存檔並可讀回，讀回後日期序列相同
- [ ] 遞增引擎版本號；舊存檔顯示「行情引擎已更新，需重新開局」
- [ ] 核心測試涵蓋：日期序列跳過週末、週末順延、第一個即時交易日與歷史倒推、存檔讀回；既有測試全部通過
