# 03: K 棒週期切換

**What to build:** 使用者可以在圖表左上角切換日 K、週 K、月 K，所有窗格同步改用該 K 棒週期：K 線、成交量、資產曲線，以及買賣點、揭曉標示。正在進行中的那一週或那一月的 K 棒隨 tick 即時長出來。規格見 `.scratch/calendar-indicators/spec.md`。

**Blocked by:** 01

**Status:** done

- [x] 模擬核心可依指定 K 棒週期回傳 K 棒序列；每根聚合 K 棒帶有起日、迄日與涵蓋的交易日索引範圍
- [x] 週 K 以同一週週一到週五分組，跨月的週不拆開；月 K 以日曆月分組；開盤取期初、收盤取期末、高低取期間極值、量為加總
- [x] 正在形成的最後一根聚合 K 棒隨 tick 更新，收盤等於當下 tick 價；預產歷史最前面不完整的週或月照樣成為一根 K 棒
- [x] 資產曲線依 K 棒週期取點：一根 K 棒一點、取期末交易日收盤值，最後一點是當下即時值，預產歷史區段留白
- [x] 圖表左上角有日 K／週 K／月 K 分段按鈕，桌面與手機相同
- [x] 週 K、月 K 期間內有買進在 K 棒下方標 ▲、有賣出在上方標 ▼，兩者都有就都標
- [x] 揭曉開啟時，市場狀態背景帶以交易日為單位畫在 K 棒寬度內；期間內任一天有跳躍就在該 K 棒上方標記
- [x] 週 K、月 K 的提示框顯示「起日–迄日」、開高低收、成交量，以及期間內買進、賣出筆數
- [x] 切換週期時：跟隨最新就維持跟隨；平移中就以右緣日期為錨點；可視根數依時間長度換算並限制在 20 根到全部
- [x] 目前的 K 棒週期寫進存檔並可讀回
- [x] 核心測試涵蓋：聚合的開高低收量、跨月週、月分組、盤中即時更新、聚合範圍首尾相接且涵蓋全部交易日、資產曲線取點數與數值
