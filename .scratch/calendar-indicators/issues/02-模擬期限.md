# 02: 模擬期限

**What to build:** 一局最多進行 30 年（從第一個即時交易日起算，不含預產歷史）。到期後行情停止、不能再下單，但使用者仍可檢視圖表、部位、績效與交易紀錄，或重新開局。30 年的存檔也要能在合理時間內讀回。規格見 `.scratch/calendar-indicators/spec.md`。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 到期日為起始日期滿 30 年的前一個交易日；該交易日收盤後，推進 tick 不再改變 K 棒與進度
- [ ] 到期後下單一律拒絕，並回傳「已達模擬期限」的拒絕原因
- [ ] 讀取狀態可得知是否已到期
- [ ] 到期時介面自動暫停，停用播放鍵、速度切換與下單按鈕，並顯示「已達模擬期限」
- [ ] 到期後圖表縮放、平移、提示框，以及部位、績效、交易紀錄面板照常可用，也可以重新開局
- [ ] 到期狀態存檔後讀回仍為到期
- [ ] 讀檔時顯示「讀取中…」
- [ ] 核心測試涵蓋：到期後推進與下單被拒絕、到期狀態存檔讀回、30 年存檔在 Node 中重算 < 3 秒
- [ ] 更新 `.scratch/stock-sim/spec.md`：Story 18「沙盒沒有終點」改為模擬期限、從 Out of Scope 移除「固定局數」、讀檔效能條目改為「30 年存檔 < 3 秒」
