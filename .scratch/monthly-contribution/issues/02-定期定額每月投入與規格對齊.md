# 02: 定期定額每月投入與規格對齊

**What to build:** 「定期定額」比較基準改為不包含初始資金，從第一個即時交易日開盤起及後續每個日曆月的第一個交易日開盤固定投入每月入金買進，單月買不完的零頭餘額滾入現金池合併買進（每月入金為 0 時不買進維持 0%），並以定期定額累計投入本金計算累計投入報酬率呈現於績效面板與資產曲線；同時確保買進持有不受每月入金影響、補齊核心測試，並同步修正既有規格文件中被取代的過時條目。規格見 `.scratch/monthly-contribution/spec.md`。

**Blocked by:** 01: 開局每月入金與使用者累計投入報酬率

**Status:** ready-for-agent

- [ ] 定期定額不包含初始資金，從第一個即時交易日開盤起及後續每個日曆月的第一個交易日開盤固定投入每月入金買進，直到模擬期限到期為止
- [ ] 定期定額單月買不完的零頭現金保留在定期定額帳戶中，下個月合併當月入金一起盡量買進（無條件捨去至整股並扣手續費）
- [ ] 當每月入金設為 0 元時，定期定額不買進且報酬率維持 0%
- [ ] 買進持有維持僅於第一個即時交易日開盤投入初始資金，後續日曆月不領取每月入金也不再買賣
- [ ] 定期定額報酬率改以其實際累計投入本金為分母計算，並於績效面板與資產曲線窗格隨 tick 即時呈現
- [ ] 存檔重算讀回後，定期定額與買進持有的累計投入本金、股數、現金、交易紀錄及報酬率與存檔前完全一致
- [ ] 核心測試涵蓋：定期定額首日買進與跨月買進、零頭餘額滾存與高股價累積買股、每月入金為 0 邊界、買進持有不受每月入金影響、三方各自累計投入報酬率與存檔讀回一致
- [ ] 同步更新初始模擬器規格與投資報告規格中被取代的「定期定額 12 期」「比較基準共用初始資金」及「報酬率以初始資金為分母」條目，避免規格間互相矛盾
- [ ] 以瀏覽器人工檢查桌面與手機版的重新開局設定、部位與績效面板及三條資產曲線顯示正常
