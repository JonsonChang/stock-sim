# 01: 開局每月入金與使用者累計投入報酬率

**What to build:** 使用者可在重新開局設定「每月入金」（預設 10,000 元，與初始資金皆允許設為 0 但兩者不可同時為 0、局中不可修改）；從次一個日曆月的第一個交易日開盤起，每月自動將每月入金撥入使用者現金與累計投入本金，並在部位面板顯示「累計投入本金」與「總損益」，使用者與買進持有報酬率改以各自的累計投入本金計算，且存檔納入每月入金並升級引擎版本。規格見 `.scratch/monthly-contribution/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 模擬核心開局設定新增每月入金參數（預設 10,000 元，允許大於等於 0），初始資金放寬為允許大於等於 0
- [x] 使用者從次一個日曆月的第一個交易日開盤起，每月自動獲得每月入金至現金與累計投入本金；開局預產歷史期間與第一個即時交易日不發放，模擬期限最後交易日若逢月初開盤照常發放
- [x] 帳戶狀態提供累計投入本金與總損益，且總損益等於總資產減去累計投入本金（亦等於已實現損益加上未實現損益）
- [x] 使用者與買進持有的報酬率及資產曲線改以各自的累計投入本金為分母計算；當初始資金為 0 元時，買進持有不買進且報酬率維持 0%
- [x] 重新開局設定區新增「每月入金」欄位（預設 10,000，最小值 0），初始資金最小值改為 0；確認開局時驗證兩者皆為有效非負數且不可同時為 0，局中維持不可修改
- [x] 部位面板新增顯示「累計投入本金」與「總損益」
- [x] 存檔開局設定納入每月入金並遞增引擎版本號為第 4 版；讀取舊版存檔時拒絕讀檔並顯示「行情引擎已更新，需重新開局」
- [x] 核心測試涵蓋：日曆月首交易日觸發（含跨週末、預產歷史與到期日邊界）、總損益恆等式、初始資金為 0 與每月入金為 0 邊界、存檔讀回一致與拒絕舊版存檔；既有模擬核心測試維持通過
