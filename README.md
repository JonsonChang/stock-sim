# 股票投資模擬器

用不會賠真錢的方式練習看盤、練習買賣判斷。

模擬器會產生一檔虛構股票的行情，走勢貼近真實市場：有大漲大跌，有多頭、空頭、盤整，也有跳空。每一局的行情都不一樣，沒辦法事先查到，也背不起來。你拿一筆初始資金，看著 K 棒一根根長出來，隨時可以買進或賣出，最後再和「買進持有」「定期定額」兩種單純策略比一比，看自己的操作是不是真的比較好。

## 開始使用

1. 用瀏覽器（建議 Chrome、Edge 或 Safari）打開 `index.html`。
2. 行情會自動開始跑，畫面上已經有大約一年的歷史 K 棒可以參考。
3. 覺得可以進場就按「買進」，想出場就按「賣出」。

不需要安裝，也不需要網路。

### K 線圖

圖表左上角提供 K 棒週期切換（日 K／週 K／月 K）與技術指標、揭曉開關（均線、KD、揭曉，預設皆為關閉；揭曉詳見下方「揭曉開關」）。

由上到下有三個窗格，共用同一條時間軸：

- **K 線圖**：紅色是漲、綠色是跌（台股習慣）。你買進的地方會標 ▲，賣出的地方會標 ▼。
- **成交量**
- **資產曲線**：你和兩個比較基準從第一天起算的報酬率。開局前就有的歷史區段沒有曲線，因為那段時間你還沒參與。

圖表平常會自動跟著最新的 K 棒。往回拖曳看歷史時會停止跟隨，並出現「回到最新」按鈕，按一下就回到最新行情。

### 右側面板

- **部位**：持有股數、平均成本（含手續費）、現金、總資產、未實現損益、已實現損益。
- **績效**：你的報酬率，以及「買進持有」「定期定額」的報酬率。可以勾選要不要在資產曲線上顯示比較基準。
- **交易紀錄**：每一筆買賣的日期、股數、成交價、手續費、證交稅，最新的排在最上面。

## 操作方式

### 電腦

| 想做的事 | 操作 |
|---|---|
| 放大、縮小圖表 | 在圖表上滾動滑鼠滾輪 |
| 看較早的行情 | 在圖表上按住左鍵左右拖曳 |
| 看某根 K 棒的開高低收與成交量 | 滑鼠移到該 K 棒上 |

### 手機

螢幕寬度較窄時會自動切換成手機版面。

| 想做的事 | 操作 |
|---|---|
| 放大、縮小圖表 | 兩指捏合或撐開 |
| 看較早的行情 | 單指左右滑動 |
| 看某根 K 棒的開高低收與成交量 | 長按該 K 棒 |
| 下單 | 按畫面底部的「買進」或「賣出」，下單面板會從底部滑出 |
| 看部位、績效、交易紀錄 | 點分頁切換 |

## 下單

只有一種下單方式：**市價單**。按下買進或賣出，就以當下價格立即全部成交。

- 以「股」為單位，可以買零股。
- 「1 張」：把數量設成 1,000 股。
- 「全部資金」：把數量設成目前現金最多能買的股數。
- 下單前會顯示預估成交金額與費用。
- 現金不夠就不能買，持股不夠就不能賣（不能融資，也不能放空）。

### 交易成本

比照台股規則：

- **手續費**：成交金額的 0.1425%，最低 20 元，買賣都要付。
- **證交稅**：成交金額的 0.3%，只有賣出時收。

### 行情規則

- 每天漲跌幅最多 ±10%，碰到漲停或跌停就停在該價格，但仍然可以用漲跌停價成交。
- 價格跳動單位比照台股。
- 週六、週日不開盤，國定假日照常開盤。

## 比較基準

用跟你一樣的初始資金，照固定規則自動交易，同樣要付手續費：

- **買進持有**：第一天開盤就用全部資金買進，之後永遠不賣。
- **定期定額**：從第一天起，每 20 個交易日用開盤價投入初始資金的十二分之一，直到資金用完。

如果你的報酬率長期贏不了這兩條線，就表示你的操作不如什麼都不做。

## 揭曉開關

行情背後有一個你平常看不到的**市場狀態**：多頭、空頭或盤整。打開「揭曉」後：

- K 線圖背景會用淡色帶標出每段時間的市場狀態。
- 發生跳躍（像突發消息造成的大漲大跌）的 K 棒上方會出現標記。

建議平常保持關閉，等操作完再打開，檢查自己當初對行情的判斷對不對。

## 種子

種子決定整段行情。**同一個種子會產生一模一樣的行情。**

- 想重玩同一段行情，就在重新開局時輸入同樣的種子。
- 想跟朋友比賽，就約好同一個種子，各自操作後比報酬率。

## 重新開局

按「重新開局」會展開設定區，可以調整：

| 設定 | 預設值 |
|---|---|
| 種子 | 留空就隨機產生 |
| 起始價 | 100 |
| 初始資金 | 1,000,000 |
| 起始日期 | 今天（遇到週末會順延到下週一） |

按「確認開局」後，**目前這一局的進度會被覆蓋，無法復原**。不想開新局就按「取消」。

一局開始後，這些設定就不能再改。

## 存檔

進度會自動儲存，不需要手動存檔。系統會在每次成交、每天收盤，以及你切換分頁或關閉頁面時存檔。

下次打開時，會回到離開時的那一刻，並先處於暫停狀態，按「播放」就能接著玩。播放速度、比較基準的勾選、揭曉開關也會一起保留。

需要注意：

- 存檔存在你目前使用的瀏覽器裡，**每個瀏覽器只有一份**。換瀏覽器或換電腦看不到原本的進度。
- 清除瀏覽器資料、或使用無痕模式時，存檔會消失或無法保存。
- 如果看到「行情引擎已更新，需重新開局」，表示模擬器更新後舊存檔無法沿用，只能重新開局。

## 常見問題

**按了買進沒反應？**
看看下單按鈕下方有沒有提示訊息，例如「現金不足」「持有股數不足」或「請輸入正整數股數」。

**圖表不動了？**
可能是你往回拖曳過圖表，按「回到最新」就會恢復跟隨。也可能是按了暫停，按「播放」繼續。

**為什麼平均成本比成交價高？**
平均成本有把買進手續費算進去。

**這些行情是真實的歷史資料嗎？**
不是。行情是電腦依照真實市場的統計特性產生的，每一局都不同，所以沒辦法事後查答案。
